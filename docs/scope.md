# Data Map Page (`scope.html`)

The Data Map (Scope) page provides a visual representation of your image library as a semantic universe. It allows you to explore relationships between images in a 2D space.

## Key Features

- **Visualization Canvas**: An interactive 2D map where each point represents an image. Images with similar content or semantic meaning are positioned closer together.
- **Interactive Controls**:
  - **Zoom In/Out**: Adjust the view level.
  - **Reset View**: Return to the default perspective.
- **Data Sync**:
  - **Sync Data**: Updates the visualization with the latest data from your database.
- **Hover Previews**: Hovering over points on the map reveals a thumbnail and details of the corresponding image.

## Usage

1. **Visualize**: Open the page to see the semantic clustering of your images.
2. **Explore**: Use zoom and drag controls to navigate through clusters of images.
3. **Inspect**: Hover over points to identify specific images.
4. **Update**: Click "Sync Data" if you have recently added or analyzed new images to update the map.

> **Note**: This feature is currently in Beta (β).
