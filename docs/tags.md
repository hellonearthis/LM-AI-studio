# Tags Page (`tags.html`)

The Tags page provides a high-level overview of your collection's metadata, allowing you to explore images through their assigned tags and identified objects.

## Key Features

- **Tabs**: Switch between "Tags" and "Objects" views to explore different types of metadata.
- **Visualization Modes**:
  - **Cloud View**: Displays items as a tag cloud, where size indicates frequency.
  - **List View**: Shows items in a structured list format.
- **Sorting & Filtering**:
  - **Sort**: Order by "Most Frequent" or "Alphabetical".
  - **Search**: Filter the visible tags/objects by name.
- **Alphabet Navigation**: Jump to specific sections when in alphabetical list view.

- **Metadata Cleaning**:
  - The system automatically strips special characters like brackets `[ ] ( ) { }` from all tags and objects.
  - **Deduplication**: Intelligent normalization (e.g., removing plurals, trimming extra spaces) ensures that "Tree" and "trees" are treated as the same concept to keep your library clean.

## Usage

1. **Explore**: Toggle between Tags and Objects tabs to see the distribution of metadata in your library.
2. **Filter**: Use the search bar to find specific tags.
3. **Change View**: Switch to List View for a more structured look, or Cloud View for a visual representation of frequency.
4. **Drill Down**: Click on any tag or object to navigate to the Search page and see all matching images.
